## Agent skills

### Issue tracker

Задачи ведутся в GitHub Issues репозитория `bndby/ratur.by`. See `docs/agents/issue-tracker.md`.

### Triage labels

Пять стандартных ролей: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: один `CONTEXT.md` и `docs/adr/` в корне репозитория. See `docs/agents/domain.md`.
